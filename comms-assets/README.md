# Comms Assets

Images referenced inside email copies in the communications calendar.

Reference them in `Copy_2026` using markdown image syntax:
`![alt text](comms-assets/filename.jpg)`

The dashboard (comms-calendar.html) renders these inline in the email preview modal.

Keep images optimized (<500KB ideally) so the dashboard loads fast.
